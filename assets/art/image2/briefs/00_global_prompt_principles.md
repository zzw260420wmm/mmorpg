# Global Image2 Prompt Principles

Use these clauses in every Image2 prompt for this project:

```text
top-down 2D game art, modern Shanghai urban life simulator, grounded slice-of-life anime atmosphere, Stardew-like gameplay readability, East Asian indie game sensibility, muted warm gray palette, faded green accents, tungsten yellow indoor light, rainy blue-gray shadows, lived-in economic pressure, clean silhouettes, consistent game-asset scale, no cyberpunk overload, no fantasy, no sci-fi, no post-apocalypse, no gacha styling, no watermark, no logo, no readable text unless requested
```

When asking for tilesets:

```text
orthographic top-down or three-quarter top-down view, tileable edges, separated cells, atlas layout, consistent lighting direction, no perspective distortion, no cast shadows crossing cell boundaries, no labels or text
```

When asking for props:

```text
individual isolated props arranged in a clean atlas grid, generous padding, transparent-safe plain background, consistent scale, readable silhouette, no merged objects, no labels, no watermark
```
